# ASKART — база данных

Ветка `database` содержит SQL-дамп MySQL и ER-диаграмму базы данных ASKART. Схема поддерживает пользователей, чаты, участников, сообщения и рабочие задачи.

## Состав

- `project_bd.sql` — дамп структуры MySQL;
- `project.pdf` — ER-диаграмма;
- `README.md` — описание назначения базы и её сущностей.

Основные таблицы: `users`, `chats`, `chatmembers`, `messages`, `tasks` и `task_assignees`.
