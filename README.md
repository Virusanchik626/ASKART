# ASKART — материалы проекта

Ветка `Documents` предназначена для документации ASKART. В ней собраны схемы, сценарии использования и текстовые материалы проекта.

## Файлы

- `Askart_module_scheme.pdf` — схема модулей системы;
- `askart_use_case.pdf` — диаграмма вариантов использования;
- `Описание предметной области_ASKART.docx` — описание предметной области;
- `ТЗ_Askart.docx` — техническое задание;
