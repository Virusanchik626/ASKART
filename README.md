# ASKART — Database

Ветка содержит материалы, связанные с проектированием базы данных
информационной системы ASKART.

## Содержание

- `project_bd.sql` — SQL-скрипт создания базы данных;
- `project.pdf` — ER-диаграмма базы данных.

## Предметная область

ASKART — корпоративный мессенджер с элементами управления
рабочими задачами.

Система предназначена для:
- обмена сообщениями между пользователями;
- создания индивидуальных и групповых чатов;
- управления участниками чатов;
- хранения истории сообщений;
- создания рабочих задач;
- назначения исполнителей;
- установки приоритетов и сроков выполнения задач;
- контроля статуса выполнения задач.

## Структура базы данных

Основные сущности:

| Таблица | Назначение |
|---|---|
| `users` | Пользователи системы |
| `chats` | Чаты |
| `chatmembers` | Участники чатов |
| `messages` | Сообщения |
| `tasks` | Рабочие задачи |
| `task_assigne...` | Исполнители задач |
